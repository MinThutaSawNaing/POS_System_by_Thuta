# AI Tool API Reference

Generated by `python generate_ai_tool_docs.py`; do not edit by hand.

These are internal agent tools, not arbitrary HTTP endpoints. The planner
receives parameter schemas from this same registry. Execution checks the
registered tool, authorization, required arguments, JSON types, enums and
declared numeric bounds. Unknown arguments are rejected, not removed.

Branch and user scope come from trusted request context, never model arguments.
Write tools retain their approval/autonomy gates. Failed tools are not evidence
for a successful answer, and failed writes must never be blindly retried.

## Sales query semantics

- Best-selling products: `get_sales_trends(all_time=true)` for lifetime
  gross unit rankings in the active branch, or `days` for a rolling period.
- `all_time=true` overrides `days`; it never means a large guessed day count.
- Trend revenue is gross line price × quantity, before returns and tax.
- `total_products_sold` counts product groups, not units or transactions.
- Missing/deleted products remain in historical rankings as unknown products.
- Summary totals: `get_sales_summary`; `limit` limits recent rows only.
- Results explicitly identify `period`, `period_days` and `branch_id`.

## `delete_product`

Permanently delete a product from the active branch. Sales and return/exchange history are always kept (those lines are only unlinked). A product that is still used in other tabs (warehouse stock or transfers, promotions, purchase order lines, supplier price agreements) is only removed with cascade=true, which deletes those records too.

- Category: `inventory`
- Mutates data: `True`
- Required role metadata: `manager` (runtime policy also applies)
- Autonomy: `approval`

### Arguments

```json
{
  "type": "object",
  "properties": {
    "product_id": {
      "type": "integer",
      "description": "The product to delete."
    },
    "confirm": {
      "type": "boolean",
      "description": "Set true only after the user explicitly confirmed deleting a product that has sales history. The sale records are kept."
    },
    "cascade": {
      "type": "boolean",
      "description": "Set true only after the user agreed to remove the product everywhere: also deletes its warehouse stock/transfers, promotions, purchase order lines and supplier price agreements."
    }
  },
  "required": [
    "product_id"
  ]
}
```
